# Клиентская HTML-страница агента

Страница-презентация агента для клиента: 6 слайдов, ссылки на
демо-ролик и на пространство, форма обратной связи. Файл —
`Демо/ИИ_агент_<имя>.html` (с подчёркиваниями) в папке плагина рядом с
роликом.

- Шаблон — `Сборка HTML агента/page_template.html`. Он самодостаточен:
  дизайн-токены, классы, навигация, форма и экспорт уже внутри;
  комментарии `SLIDE N` и плейсхолдеры `{{…}}` показывают, что куда
  ставить.
- Эталон заполнения — `Сборка HTML агента/Примеры/ИИ_агент_финансового_контролёра.html`.
- CSS, JS навигации, разметку формы и `exportToExcel()` копировать из
  шаблона как есть: не «нормализовать» и не переизобретать.

## Состав — ровно 6 слайдов

| # | Слайд | Содержание | Источник фактов |
|---|---|---|---|
| 1 | Титул | имя агента, категория, «Назначение: …» | `plugin.yaml`, агент |
| 2 | Проблематика | до 4 проблем, которые снимает агент | README, план |
| 3 | Решение | назначение агента; навыки карточками (span 6 при ≤ 4 навыках, span 4 при 5–7) | агент: «Роль», «Навыки» |
| 4 | Применение | «Когда применять» / «Как применять» | агент: «Принципы», «Границы»; триггеры навыков |
| 5 | Эффекты | 3 метрики, ниже «Качественные преимущества» и «Дополнительные материалы» со ссылками | только счётные факты: число навыков, команд, режим работы |
| 6 | Обратная связь | форма из 6 вопросов + «Скачать ответы в Excel» | без изменений из шаблона |

На каждом контентном слайде порядок такой: kicker (раздел) → заголовок
→ контент.

## Правила контента

- Факты берутся только из материалов плагина: `plugin.yaml`, `README.md`,
  `agents/`, `skills/`, `commands/` и план. Маркетинговые проценты не
  выдумывать.
- Ссылки только реальные: ролик — публичная ссылка файлообменника,
  пространство — workspace, в котором записывалось демо. Полный URL
  ставится в `href`, видимый текст — краткий.
- Имена полей формы (`overall_rating`, `likes_dislikes`,
  `client_customization`, `not_interested_reason`, `universality`,
  `scaling_improvements`) не переименовывать: их читает экспорт.

## Технические требования

- Единственный внешний ресурс — SheetJS CDN из шаблона, он нужен для
  экспорта формы.
- `@font-face` нет: стек `"SB Sans Display", Arial, sans-serif` работает
  с fallback на Arial.
- `<title>` = `Имя агента — GigaCowork`; `lang="ru"`.
- Только светлая тема и только цвета и отступы из токенов шаблона.
