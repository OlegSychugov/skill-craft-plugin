# DEMO-VIDEO — съёмка и монтаж демо-видео работы плагина

Опциональный слой (как `auto-test.md`): применяется только по явной просьбе
пользователя — «запиши видео», «сними демо», «сделай ролик».

Целевой вид ролика: **1:20–1:40**, 1280×800, WebM (VP8), без звуковой
дорожки — озвучка не входит в стандарт, весь смысл несут субтитры. Старт —
сразу с загруженной страницы (без белого экрана и
спиннеров). Ни одного статичного экрана дольше ~3–4 с; ключевые моменты
(отправка задачи, панель навыков, таблица результата) — в реальном времени.

Эталон: демо плагина «ИИ-агент финансового контролёра» —
`backlog/02. Testing/financial-controller/Демо/` (оригинал 7:15 →
`_short.webm` 1:22 → `_short_subtitled.webm`).

## 1. Два способа записи

### 1.1 Основной — Playwright recordVideo (рекомендуется)

Записывается сама страница (композитор браузера), поэтому способ не зависит
от состояния десктопа: работает на залоченном компьютере, поверх созвонов и
любых окон. Логин в платформу берётся из профиля Playwright MCP.

```
1. browser_run_code_unsafe: state = page.context().storageState()
2. ctx2 = browser.newContext({ storageState: state,
       viewport: {1280, 800},
       recordVideo: { dir: '<tmp>/video', size: {1280, 800} } })
3. p2 = ctx2.newPage(); p2.goto(<workspace URL>)
4. … демо: прикрепить файл (setInputFiles на скрытый
   input[type=file]), отправить запрос, дождаться ответа …
5. p2.close() → ctx2.close()   # close финализирует видеофайл
6. v = await p2.video(); path = await v.path()   # путь узнать ДО close
```

Подводные камни:

- Требуется ffmpeg-билд Playwright: `cmd /c "npx playwright install ffmpeg"`
  (именно `cmd /c` — PowerShell-политика запрещает запуск npx.ps1).
- Sandbox `browser_run_code_unsafe` не хранит глобальные переменные между
  вызовами. Контекст, созданный в одном вызове, в следующем ищут через
  `browser.contexts().find(c => c.pages().some(p => p.url().includes('<id>')))`.
- Файл `.webm` дописывается на диск по мере записи, но валиден полностью
  только после `page.close()`.

### 1.2 Альтернатива — расширение браузера (Scre.io «Запись экрана»)

Даёт «экранный» ролик (виден браузер целиком), но требует: разблокированного
десктопа, монопольного фокуса на окне записи ~3–5 минут, и клика по
системному диалогу выбора источника (кликается клавиатурой/мышью на уровне
ОС — не через CDP). Если во время записи пользователь работает за
компьютером (созвон, ввод текста) — кадр будет испорчен. При конфликте —
фолбэк на способ 1.1 без согласования.

## 2. Сценарий демо (готовится ДО записи)

- Демо-данные с заранее заложенными рисками (например, реестр заявок с
  дублем и превышением лимита — генерируется openpyxl, скрипт-образец в
  `Данные для тестирования` плагина).
- Файл прикрепляется **в кадре** (это важный момент демонстрации).
- Запрос — одной фразой, по нему понятно, что делает агент.
- Дождаться 100% и итогового документа; финал держится на экране (в монтаж
  пойдёт как 1x-сегмент).

## 3. Конвейер монтажа

Скрипты — в `Референсы/Съёмка демо-видео/`; константы (пути, пороги) —
наверху каждого файла.

| Шаг | Инструмент | Результат (в скобках — кейс §4) |
|---|---|---|
| 1. Запись | Playwright recordVideo (§1.1) | исходник `.webm` (7:15, 1280×800, 20 МБ) |
| 2. Анализ статики | `analyze_idle.py <исходник>` | блоки `(start, end, len)` ≥ 4 с → `idle_blocks.json` |
| 3. Момент отрисовки | PNG-пробы кадров (§5.1) | t отрисовки (≈ 9.3 с) — точка старта ролика |
| 4. Карта правки | таблица `segments` в `make_short.py` | `(start, end, speed, описание)` — правила §5.2, эталон §4 |
| 5. Рендер | `make_short.py` | `_short.webm` 80–100 с (1:22, 8.6 МБ) |
| 6. Субтитры | `make_subtitles.py` | `_short_subtitled.webm` + `_short.vtt` (§6) |
| 7. Итоговая страница | page_template.html (§7) | презентация со ссылками (пространство + видео) |

вырезаны по PNG-пробам) → итог 1:22. Из 426 с полезной записи в 1x

Выводы кейса:

## 5. Монтаж

### 5.1 Анализ «висящих» участков — `Съёмка демо-видео/analyze_idle.py`

Дамп кадров 2 fps → scale 64×36 → gray → rawvideo в pipe. Кадр считается
статичным, если изменилось <2% пикселей (|Δ|>30); статичные серии ≥4 с —
кандидаты на ускорение. Скрипт печатает блоки `(start, end, len)`.

Грабли:

- `proc.stdout.read(n)` на пайпе возвращает куски произвольной длины —
  читать строго `read_exact(n)` в цикле, иначе получение кадров молча
  обрывается на первом кадре.
- Урезанный ffmpeg из Playwright (`ms-playwright\ffmpeg-1011`) содержит
  только scale/png/libvpx — нет ни rawvideo-муксера, ни trim/setpts/concat.
  Для анализа и монтажа ставится полный билд: `pip install imageio-ffmpeg`,
  путь — `imageio_ffmpeg.get_ffmpeg_exe()`.
- Момент фактической отрисовки страницы ищется по размерам пробных PNG
  (белые кадры ~5 КБ, контентные — сотни КБ); ролик начинается от
  `(момент отрисовки − 1 с)`, белые кадры вырезаются.

### 5.2 Карта правки — правила

| Контент | Скорость |
|---|---|
| Белый экран / «Загрузка…» | вырезать целиком |
| Курсор до меню, ожидание ввода | ×20–×25 |
| Прикрепление файла + ввод запроса | ×8–×20 |
| Отправка задачи | 1x |
| Ожидание работы агента (фоновые расчёты) | ×12–×16 |
| Панель «Прогресс/Навыки», результат-таблица, итоговый документ | 1x (5–15 с) |
| Финальный кадр (прокрутка к ответу) | 1x (15–20 с) |

Каждой смене скорости — 4–6 с «воздуха» на 1x до и после, чтобы склейка
читалась. Ориентир итога: 80–100 с.

### 5.3 Рендер — `Съёмка демо-видео/make_short.py`

Один проход ffmpeg: на каждый сегмент
`[0:v]trim=start:S:end:E,setpts=(PTS-STARTPTS)/speed[sN]`, затем
`concat=n=N:v=1:a=0` → `fps=25` → `libvpx -crf 10 -b:v 2M -auto-alt-ref 0 -an`.
Сегменты задаются таблицей `(start, end, speed, описание)` — готовый
пример заполнения: §4 (закомментирован и в самом `make_short.py`).

## 6. Субтитры — `Съёмка демо-видео/make_subtitles.py`

Два артефакта из одного списка титров `(start, end, текст)`:

1. **Вшитые** — цепочка `drawtext` (по фильтру на титр,
   `enable='between(t,a,b)'`, textfile во внешнем файле).
   Оформление: fontsize 23, белый, чёрная подложка `black@0.45`,
   `y=h-th-42` (нижний центр).
2. **Мягкие** — `.vtt` рядом с роликом; подключается тегом `<track>`
   к `<video>`: `<track kind="subtitles" src="*.vtt" srclang="ru" default>`.

Грабли drawtext:

- Абсолютные Windows-пути внутри filtergraph недопустимы: двоеточие диска
  (`C:`) рвёт парсер опций, обратные слэши съедаются эскейпом. Решение:
  запускать ffmpeg с `cwd=<папка титров>` и передавать `fontfile=font.ttf`,
  `textfile=cap01.txt` по относительным именам (шрифт заранее копируется
  в эту папку под ASCII-именем).
- Текст тируется во внешний `textfile` с `encoding="utf-8-sig"` (BOM) —
  надёжное чтение UTF-8 кириллицы; внутри текста не используются `:`, `'`.
- В Python-шаблоне подстановки имя файла подставляйте `{n:02d}` (`.format`),
  а не `%02d` — percent-стиль внутри `.format()` не подставится.

## 7. Итоговая страница

Клиентская презентация по шаблону
`Референсы/Сборка HTML агента/page_template.html` — финал конвейера, лежит
рядом с артефактами демо, в папке `Демо/` плагина рядом с роликом. Эталон —
страница кейса financial-controller:
`backlog/02. Testing/financial-controller/Демо/ИИ_агент_финансового_контролёра.html`.
Стандарт страницы — `AGENT-HTML.md`.

Порядок: загрузить ролик на файлообменник (публичная ссылка) → заполнить
плейсхолдеры шаблона фактами из материалов плагина (plugin.yaml, README.md,
skills/, commands/) → проверить страницу в браузере.

Видео-ссылка: выгрузка на `<cfg:video_share_url>`, папка `<cfg:video_share_folder>`;
автоматом через Playwright, фолбэк — пользователь загружает вручную.
Публичную ссылку проверять в чистой вкладке: страница файла должна
открываться без редиректа на авторизацию. Мягкие субтитры (`.vtt`) на
файлообменнике не работают — публиковать ролик с вшитыми титрами
(`_short_subtitled.webm`).

Пространство: ссылка того workspace, в котором записывалось демо.

Правила: ссылки только реальные (AGENT-HTML.md §5), URL не изобретать;
контент — только из материалов плагина; блок `@font-face` не добавлять
(ассета со шрифтом нет, фолбэк Arial); единственный внешний скрипт —
SheetJS CDN формы обратной связи.

## 8. Чек-лист приёмки ролика

- [ ] Первый кадр — загруженная страница пространства, без белого экрана.
- [ ] Нет статичных участков дольше ~3–4 с (проверка analyze_idle.py на
      итоговом файле даёт 0 блоков ≥4 с, кроме финала ≤20 с).
- [ ] Видны: прикрепление файла, отправка запроса, панель «Навыки»,
      результат (таблица/документ) — все в 1x.
- [ ] Субтитры не перекрывают значимый контент; опечаток нет; факты титров
      соответствуют происходящему (ничего не выдумано).
- [ ] Хронометраж 1:20–1:40; размер файла < 15 МБ.
- [ ] Рядом лежат: исходник `_short.webm` и `_short.vtt`.
- [ ] Итоговая страница собрана: обе ссылки реальны и открываются; видео —
      публичная ссылка; страница самодостаточна (кроме SheetJS CDN).
