# Настройки окружения `<cfg:…>`

Адреса и пути не зашиты в навыки: в тексте они записаны как
`<cfg:ключ>`. Значения хранятся в `.skill-craft.json` в корне рабочего
места — папке, где лежат каталог витрины и конвейер. Образец —
`../skill-craft.config.example.json`.

| Ключ | Что это |
|---|---|
| `catalog_dir` | каталог витрины (git-репозиторий; все git-команды выполняются в нём) |
| `plugins_dir` | опубликованные плагины внутри каталога |
| `ideas_dir` / `todo_dir` / `testing_dir` / `archive_dir` | папки конвейера: идеи / черновики / тестирование / архив |
| `demos_dir` | демо-материалы |
| `hub_repo_url` | веб-адрес репозитория витрины |
| `hub_base_branch` | основная ветка (`master` или `main`) |
| `hub_pr_url` | ссылка на создание PR, шаблон с `{base}` и `{branch}` |
| `demo_stand_url` | демо-стенд Cowork |
| `video_share_url` / `video_share_folder` | файлообменник и папка демо-роликов |
| `plugins_map_path` | `Plugins-map.md` |

Пути указываются относительно корня рабочего места.

Если файла или нужного ключа нет, спроси у пользователя только
недостающие ключи, создай или дополни `.skill-craft.json` и добавь его в
`.git/info/exclude` каталога витрины. Значения не выдумывать.
