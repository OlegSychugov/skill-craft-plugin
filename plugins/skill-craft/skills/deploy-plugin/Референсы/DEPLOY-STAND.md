# Демо-стенд Cowork: ручное развёртывание плагина

Интерфейс зафиксирован 2026-09-30 на `<cfg:demo_stand_url>`. Если стенд
выглядит иначе, верь стенду и отметь расхождение в отчёте.

## Карта полей «источник → стенд»

| Источник | Поля | Куда на стенде |
|---|---|---|
| `plugin.yaml` | `name`, `description` | форма пространства |
| заголовок `agents/*.md` | `name`, `description` | форма агента |
| тело `agents/*.md` после `---` | — | поле «Инструкция» агента |
| `skills/<alias>/` | папка целиком | ZIP навыка |
| заголовок `commands/*.md` | `name`, `description` | форма команды |
| тело `commands/*.md` | — | поле «Инструкции» команды |

Заголовок агента в инструкцию не копируется: поля `skills` и
`temperature` интерфейс игнорирует, навыки привязываются отдельно.

## Путь в интерфейсе

1. **Пространство:** `/workspaces` → «Создать пространство» → название
   и описание → «Создать» → `/workspaces/<uuid>`.
2. **Агент:** вкладка «Агенты» → «Создать агента» → три поля →
   «Сохранить» → `/workspaces/<ws>/agents/<uuid>/settings`.
3. **Навыки:** вкладка «Навыки» → «Добавить навык» → «Загрузить файл
   навыка» (не «Написать инструкцию» и не «Добавить из витрины») → зона
   «Перетащите файл или папку…» → `<alias>.zip` → «Далее» → карточка со
   статусом «Добавлено». Один навык — один ZIP: собирай его через
   `pack_skill.py`; input принимает один файл.
4. **Команды:** «Ещё вкладки» → «Команды» → «Управление командами» →
   «Создать команду» → имя, описание, инструкции → «Создать команду».
   Массового создания нет, команды добавляются по одной.
5. **Привязка:** в настройках агента «Добавить в „Навыки“» и «Добавить
   в „Команды“» → «Добавить» у каждого элемента плагина → **«Сохранить»
   внизу формы**, без этого привязки теряются. Системные навыки уже
   подключены, их не трогать. Системную команду «Узнать о возможностях
   чата» не добавлять.

## Проверка

В настройках агента: «Навыки» = 11 системных + N навыков плагина;
«Команды» = M команд плагина. Пространство видно в `/workspaces`,
агент — во вкладке «Агенты», у каждого навыка статус «Добавлено».

## Грабли браузерной автоматизации (Playwright)

| Симптом | Причина | Обход |
|---|---|---|
| `Ref not found` при клике | refs меняются после каждого действия | искать элемент заново по тексту перед каждым кликом |
| `browser_file_upload` не срабатывает | нужен открытый диалог выбора файла | сначала клик по зоне выбора, затем upload |
| `File access denied ... outside allowed roots` | ZIP вне разрешённых корней | скопировать в рабочую папку, после загрузки удалить копию |
| «Можно загрузить только один файл» | в input остался прежний файл | «Удалить выбранный файл» и выбрать заново |
| нужно считать счётчики | значения есть в тексте страницы | regex по `document.body.innerText`: `/(Навыки\|Команды\|Интеграции)\s*\n?\s*(\d+)/g` |
