Проблематика

Бизнес-проблемы при закупке МТР

🔍

Отсутствие видимости остатков

Закупаются позиции, которые фактически есть на складах компании. Отсутствие единой системы поиска по 110 000+ номенклатурным позициям на множестве складов и организаций.

💰

Избыточные закупки

Дублирование закупок из-за незнания о существующих аналогах. Компания несёт дополнительные расходы, когда можно использовать имеющиеся на складах ресурсы.

⏱️

Ручной поиск аналогов

Технические специалисты тратят часы на ручной поиск аналогов в Excel-таблицах и веб-поиск характеристик. Высокий риск человеческой ошибки при сравнении спецификаций.

📊

Несогласованность данных

Разные наименования одной номенклатуры в системах, отсутствие нормализации. Одна и та же позиция может называться по-разному на разных складах.

Как работает агент

Сценарий 1: Найдено точное совпадение

1

Получение МТР на входе

Агент получает наименование МТР текстом от пользователя или из загруженного файла со списком позиций к закупке.

2

Поиск в Своде запасов

Выполняется поиск точного совпадения по столбцу «Номенклатура» с учётом нормализации (регистр, пробелы, кавычки). При совпадении извлекается Код КСМ.

3

Сбор данных со всех складов

Все строки с найденным Кодом КСМ извлекаются — каждая комбинация «Организация + Склад» становится отдельной строкой отчёта.

4

Формирование Excel-отчёта

Создаётся файл с оформлением: заголовки, границы, условная подсветка статуса «Точное совпадение» зелёным. Автоширина столбцов, закреплённая шапка.

✅ Результат

Агент формирует отчёт, в котором показано: на каких складах (номера складов) и в каких организациях (ООО «...») находится данный МТР, с указанием доступного количества по каждой позиции.

Как работает агент

Сценарий 2: Поиск аналогов через веб-поиск

1

Получение МТР на входе

Агент получает наименование МТР текстом или из файла со списком позиций к закупке.

2

Поиск точного совпадения в Своде запасов

Поиск по столбцу «Номенклатура». Если найдено — переход к сценарию 1. Если не найден — продолжение работы.

3

Определение класса материалов

Анализ аналогичных строк в файле для определения класса материалов. Подтверждение класса у пользователя через question.

4

Формирование списка потенциальных аналогов

Фильтрация по классу материалов, сужение до релевантных позиций по ключевым характеристикам (тип, размер, класс).

5

Определение технических критериев

Веб-поиск для уточнения спецификации искомого МТР. Определение 3-5 ключевых критериев сравнения (ДУ, РУ, материал и др.).

6

Поиск характеристик аналогов

Веб-поиск по каждой позиции потенциальных аналогов для уточнения технических характеристик. Промежуточные чек-пойнты.

7

Сравнение потенциальных аналогов

Сравнение по критериям. Статусы: «Полный аналог» (все критерии совпадают) или «Требует согласования» (незначительные отклонения).

8

Формирование итогового Excel-отчёта

Создание отчёта со всеми найденными аналогами, фан-аут на все склады/организации, цветовая индикация статусов.

Постановка задачи и входные данные

📋 Исходный запрос пользователя

Наименование МТР: «Антифриз Kixx Antifreeze G12+»

Цель: Найти имеющиеся остатки на складах компании или подобрать аналоги для закупки

Контекст: Закупочный отдел планирует закупку антифриза. Перед размещением заказа необходимо проверить наличие на складах ННК и выявить возможные аналоги для оптимизации расходов.

🗂️ Источник данных

Файл: «Свод запасов.xlsx»

Объём базы: 112 295 строк × 14 столбцов

Ключевые поля: Номенклатура, Класс материалов, Код КСМ, Организация, Склад, Конечный остаток

Особенность: Значения в столбце «Номенклатура» не нормализованы — свободный текст с сокращениями, синонимами, разным порядком слов, опечатками.

🎯 Задача агента

По заданному наименованию МТР найти: (1) точное совпадение этого МТР на остатках складов компании; (2) либо полный аналог — позицию с идентичными техническими характеристиками; (3) либо позицию, которая может быть аналогом при согласовании технического эксперта — с несущественными отклонениями характеристик; (4) либо констатировать, что аналогов на складах нет и требуется внешняя закупка.
