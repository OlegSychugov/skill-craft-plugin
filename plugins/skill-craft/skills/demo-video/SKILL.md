# demo-video — демо-ролик для клиента

## Цель

Снять и смонтировать ролик плагина `$ARGUMENTS`, который можно сразу
отправить клиенту: за 40–100 секунд видно, что агент делает и какой
результат даёт.

## Вход и выход

- Вход: плагин развёрнут на стенде (иначе сначала `deploy-plugin`),
  есть URL демо-пространства на `<cfg:demo_stand_url>`. Логин выполняет
  пользователь.
- Рабочая папка: `<cfg:testing_dir>/<alias>/Демо/`.
- Выход: MP4 (основной), WebM, обложка, `edit.json`, `events.json`.

## Опора

`Референсы/DEMO-VIDEO.md` — каким должен быть ролик, запись с журналом,
монтаж, звук, приёмка, грабли. Скрипты — `Референсы/Съёмка демо-видео/`;
оригиналы не правь, сценарий пиши в `Демо/edit.json`.

## Границы

- Сценарий `edit.json` согласовать с пользователем до записи.
- Тексты в кадре — только факты из ответа агента и материалов плагина.
- Голос — только по просьбе; музыку и права на неё даёт пользователь.
- Приёмка включает просмотр каждого листа раскадровки, а не только код
  возврата `qa_video.py`.
- Публикация ролика и клиентская страница — команда `agent-page`.

## Отчёт

Пути к MP4, WebM и обложке; длительность и размер; результат
`qa_video.py`; итог визуальной проверки; что пришлось перезаписать.
