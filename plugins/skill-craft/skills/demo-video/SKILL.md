# demo-video — демо-ролик для клиента

Сними и смонтируй демо-ролик плагина `$ARGUMENTS`, который можно
отправить клиенту. Явный вызов команды — это просьба пользователя
включить слой DEMO-VIDEO.

## Предусловия

- Загрузи навык `skill-craft` и прочитай
  `../skill-craft/Референсы/DEMO-VIDEO.md` целиком. Скрипты —
  `../skill-craft/Референсы/Съёмка демо-видео/` (`record_events.js`,
  `auto_edit.py`, `qa_video.py`, `edit.example.json`); оригиналы не правь.
- Плагин развёрнут на стенде (иначе — сначала `deploy-plugin`), есть URL
  демо-пространства на `<cfg:demo_stand_url>` (навык `skill-craft`, раздел
  «Настройки окружения»). Логин выполняет пользователь.
- Инструменты: браузер с Playwright, Python, `imageio-ffmpeg`. Установку
  пакетов предложи и выполни только после согласия пользователя.
- Рабочая папка — `<cfg:testing_dir>/<alias>/Демо/`.

## Шаги

- [ ] 1. Демо-данные по §2.3: деловые названия, без «Ромашек», брендов и
      ФИО, неокруглённые суммы. Не так — пересобери данные до записи.
- [ ] 2. Стенд по §2.2: чистое пространство, служебные файлы не попадают в
      «Документы», навык стабилен (без сцен отладки). Пробный прогон без
      записи.
- [ ] 3. Сценарий — `Демо/edit.json` по `edit.example.json`: события,
      holds с зумом, главы, плашки, карточки. Согласуй с пользователем.
- [ ] 4. Запись по §3: `record_events.js` в `addInitScript`, старт сразу
      по URL пространства, метки событий, сцена результата (открыть и
      показать каждый созданный файл). Сохрани `_raw.webm` и `events.json`.
- [ ] 5. Монтаж: `python auto_edit.py Демо/edit.json`; длительность
      60–100 с — иначе правь holds и скорости.
- [ ] 6. Приёмка: `python qa_video.py <ролик>.mp4 <ролик>_timeline.json`
      (PASS) и **просмотр каждого листа раскадровки** по визуальному
      чек-листу. Дефект записи — перезапись, дефект монтажа — `edit.json`.
- [ ] 7. Чек-лист §9.

## Ограничения

- Факты в главах, плашках и карточках — только из ответа агента и
  материалов плагина.
- Голос — только по просьбе пользователя; музыку и права на неё даёт
  пользователь.
- Публикацию ролика и итоговую страницу делает `agent-page`.

## Формат отчёта

Пути к MP4, WebM, обложке, VTT; длительность и размер; результат
`qa_video.py`; итоги визуальной проверки по листам; что пришлось
перезаписать или поправить.
