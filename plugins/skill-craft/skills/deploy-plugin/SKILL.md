# deploy-plugin — развёртывание на демо-стенде

Разверни плагин `backlog/02. Testing/$ARGUMENTS/` на демо-стенде через
браузер. Это не гейт публикации — команда доводит плагин до работающего
состояния на стенде.

## Предусловия

- Загрузи навык `skill-craft` и прочитай
  `../skill-craft/Референсы/auto-test.md` целиком: путь в UI, карта полей,
  упаковка ZIP, подводные камни Playwright. Источник правды — сам стенд:
  при расхождении UI с документом действуй по факту и отметь это в отчёте.
- Нужен инструмент управления браузером (Playwright MCP или аналог). Нет —
  остановись и выдай пользователю пошаговую инструкцию из auto-test.md
  для ручного выполнения.
- Адрес стенда — `<cfg:demo_stand_url>` (навык `skill-craft`, раздел
  «Настройки окружения»).
- Логин на стенде выполняет пользователь. Креды не искать и не
  запрашивать; дождись, пока пользователь сообщит, что вошёл.

## Шаги

- [ ] 1. Проверь структуру плагина (auto-test.md §2): `plugin.yaml`,
      `agents/*.md`, `skills/<alias>/SKILL.md`, `commands/*.md`. Составь
      карту полей «источник → поле на стенде».
- [ ] 2. Упакуй каждый навык в ZIP **tar'ом** (не `Compress-Archive`):
      `tar -a -c -f <alias>.zip -C <путь\к\skills> <alias>`. ZIP — в
      разрешённый корень браузерного инструмента.
- [ ] 3. Пространство (§3) — запомни `<uuid>`.
- [ ] 4. Агент (§4) — инструкция = тело `agents/*.md` после `---`.
- [ ] 5. Навыки (§5) — по одному ZIP, до статуса «Добавлено».
- [ ] 6. Команды (§6) — по одной.
- [ ] 7. Привязка к агенту (§7) и «Сохранить».
- [ ] 8. Верификация (§8): чек-лист и счётчики «Навыки»/«Команды».
- [ ] 9. Удали временные копии ZIP из разрешённого корня.

## Ограничения

- Системные навыки и системную команду «Узнать о возможностях чата» не
  трогать.
- Ничего не удалять на стенде без подтверждения пользователя.

## Формат отчёта

URL пространства и агента, таблица «навык/команда → статус», значения
счётчиков, чек-лист §8 с отметками, расхождения UI с документом.
Следующий шаг: прогон по `ПРОТОКОЛ_DEMO.md` (`test-plugin`) или `demo-video`.
