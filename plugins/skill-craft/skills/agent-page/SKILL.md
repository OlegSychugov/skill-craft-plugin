# agent-page — клиентская страница агента

## Цель

Дать клиенту одну страницу, по которой понятно, что делает агент и
зачем он нужен, и с которой можно открыть ролик и пространство. Всё на
странице — правда из материалов плагина.

## Вход и выход

- Вход: плагин `$ARGUMENTS` в `<cfg:testing_dir>/` (или в
  `<cfg:plugins_dir>/`, если уже опубликован), готовый ролик в `Демо/`
  (`demo-video`) и URL пространства, в котором записывалось демо.
- Выход: `Демо/ИИ_агент_<имя>.html`.

## Порядок

1. **Ролик.** Если ещё не опубликован — загрузи MP4 на
   `<cfg:video_share_url>` в папку `<cfg:video_share_folder>` (через
   браузер; не получается — попроси пользователя загрузить вручную).
   MP4 проигрывается везде, включая PowerPoint и мессенджеры. Проверь
   публичную ссылку в чистой вкладке: она должна открываться без
   редиректа на авторизацию.
2. **Страница** — по `Референсы/AGENT-HTML.md`: скопируй шаблон в
   `Демо/`, заполни по фактам, открой в браузере, пройди все слайды и
   обе ссылки.

## Границы

- Без обеих реальных ссылок (видео и пространство) страницу не собирать:
  задай один вопрос пользователю, URL не изобретать.
- Существующие страницы без просьбы не переделывать.

## Отчёт

Путь к странице, обе ссылки, источники фактов по слайдам, чек-лист
страницы с отметками.
