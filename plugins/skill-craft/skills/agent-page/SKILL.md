# agent-page — итоговая HTML-страница агента

Собери клиентскую страницу агента плагина `$ARGUMENTS`:
`Демо/ИИ_агент_<имя>.html`.

## Предусловия

- Загрузи навык `skill-craft` и прочитай
  `../skill-craft/Референсы/AGENT-HTML.md` (стандарт страницы) и
  `../skill-craft/Референсы/DEMO-VIDEO.md` §7 (публикация ролика).
  Шаблон — `../skill-craft/Референсы/Сборка HTML агента/page_template.html`,
  эталон — `…/Примеры/ИИ_агент_финансового_контролёра.html`.
- Нужны **обе реальные ссылки**: публичная на видеоролик и на workspace.
  Нет хотя бы одной — спроси пользователя; без ссылок страницу не собирать.
  URL не изобретать.

## Шаги

- [ ] 1. Видео: если ролик ещё не опубликован — выгрузи
      `_short_subtitled.webm` (вшитые титры) по DEMO-VIDEO.md §7 или попроси
      пользователя загрузить вручную. Файлообменник —
      `<cfg:video_share_url>`, папка `<cfg:video_share_folder>` (навык
      `skill-craft`, раздел «Настройки окружения»). Проверь публичную ссылку в чистой
      вкладке (без редиректа на авторизацию).
- [ ] 2. Собери факты из материалов плагина: `plugin.yaml`, `README.md`,
      `skills/`, `commands/`. Ничего сверх них.
- [ ] 3. Скопируй шаблон в `<cfg:testing_dir>/<alias>/Демо/` (или
      `<cfg:plugins_dir>/<alias>/Демо/`, если плагин уже опубликован) под
      именем `ИИ_агент_<имя>.html` (подчёркивания, как в эталоне).
- [ ] 4. Заполни плейсхолдеры по каркасу и правилам контента AGENT-HTML.md.
- [ ] 5. Технические требования: самодостаточный файл, без `@font-face`,
      единственный внешний скрипт — SheetJS CDN.
- [ ] 6. Открой страницу в браузере, пройди все слайды, проверь обе ссылки.
- [ ] 7. Чек-лист приёмки страницы из AGENT-HTML.md.

## Ограничения

- `agent.html` в корне плагина не создавать — это отменённый стандарт.
- Существующие страницы не переделывать без просьбы.

## Формат отчёта

Путь к странице, обе ссылки, источники фактов по слайдам, чек-лист
приёмки с отметками.
