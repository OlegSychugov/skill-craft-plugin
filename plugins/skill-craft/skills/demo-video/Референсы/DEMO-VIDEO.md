# Демо-ролик плагина для клиента

Цель — ролик, который не стыдно отправить клиенту: польза видна с первых
секунд, ожидание не показано, результат крупно, длительность по
содержанию. Конвейер: журнал событий при записи → автомонтаж по журналу
→ автоматическая и визуальная приёмка.

Скрипты лежат в `Съёмка демо-видео/`; вход, выход и параметры описаны в
их docstring, а поля сценария — в `edit.example.json`. Нужны Python и
`imageio-ffmpeg` (ffmpeg из Playwright урезан). Пакеты ставятся только с
согласия пользователя.

| Скрипт | Роль |
|---|---|
| `record_events.js` | видимый курсор + журнал событий с рамками элементов |
| `auto_edit.py` | монтаж: обрезка, сжатие ожидания, зум, главы/субтитры, карточки → MP4, WebM, обложка |
| `brand_cards.py` | титульная и финальная карточки; предпросмотр — `python brand_cards.py edit.json` |
| `qa_video.py` | автоприёмка + листы раскадровки |
| `voiceover_edge.py` | озвучка без API-ключей (Edge TTS) |
| `analyze_idle.py` | поиск статичных участков в любом ролике |

## 1. Как должен выглядеть ролик

- **Сначала польза:** титульная карточка (3 с) — кто агент и что даёт.
  Дальше запрос, сжатая работа агента, результат, финальная карточка с
  2–4 итогами в цифрах и пометкой «Данные в демо вымышлены».
- **Ожидание не показываем:** пока агент думает, участок сжимается до
  ≤ 1,5 с. Бейдж «Ускорено ×N» по умолчанию выключен (`"badge": true` —
  только по просьбе). Ввод запроса идёт в живом темпе.
- **Результат — главный кадр:** каждый созданный файл открыт и показан,
  итоговые цифры читаются. Таблицы и сводки агент выводит на холст (в
  запросе — «покажи … на холсте»); превью xlsx растровое и мылится,
  поэтому показывается коротко (≤ 2 с), как факт «файл открывается».
- **Камера по умолчанию стоит:** зум ставится только на 2–4 явных
  акцента (готовый файл, итог, находки), но не на отправку запроса и не
  на прогресс.
- **Одна текстовая система:** либо субтитры внизу (`subtitles`), либо
  главы и плашки (`chapters`, `callouts`), но не всё сразу.
- **Чистота кадра:** только демо-пространство, демо-данные и результат;
  без списка пространств, чужих клиентов, служебных файлов и сцен, где
  агент чинит свою ошибку.
- **Длительность:** 40–100 с — скрипты проверяют именно этот диапазон.
  Если ролик не укладывается, правь holds и скорости, а не обрезай
  результат и не растягивай статику.

## 2. Подготовка

- **Данные** — по `../../skill-craft/Референсы/DEMO-DATA.md`. Если не так,
  пересобери данные до записи.
- **Стенд** — отдельное демо-пространство, профиль без аватара и ФИО.
  Если в «Документах» видны служебные файлы, сначала чинится навык,
  потом идёт запись. Перед записью — пробный прогон.
- **Сценарий** — `Демо/edit.json` по образцу `edit.example.json`:
  события, holds, тексты, карточки. Тексты — только факты из ответа
  агента и материалов плагина. Сценарий согласуется с пользователем.

Типовые события: `start`, `send`, `skill_panel`, `file_ready`,
`result_open`, `result_scroll`, `canvas_open`, `canvas_scroll`, `final`,
`findings`.

## 3. Запись с журналом событий

Основной способ — Playwright `recordVideo`: записывается сама страница,
поэтому запись работает и на заблокированном компьютере. Логин берётся из
профиля Playwright MCP; креды не запрашиваются.

```
1. state = await page.context().storageState()
2. ctx = await browser.newContext({ storageState: state,
       viewport: { width: 1920, height: 1080 },
       recordVideo: { dir: '<tmp>/video', size: { width: 1920, height: 1080 } } })
3. await ctx.addInitScript({ content: <текст record_events.js> })
4. p = await ctx.newPage(); video_start_ms = Date.now()      # в том же вызове
5. await p.goto('<URL демо-пространства>')                   # сразу внутрь
6. исчезла «Загрузка интеграций» → __demo.mark('start', null)
7. мышь — page.mouse.move(x, y, {steps: 25}) перед кликом; ввод — keyboard.type(текст, {delay: 35});
   ключевой момент виден на экране → __demo.mark('<событие>', '<селектор для зума>')
8. результат: двойной клик по файлу в «Документах» → превью → mark('result_open') →
   «Закрыть» → плавная прокрутка ответа (wheel по 120 px, паузы 150 мс) → mark('result_scroll');
   холст: «Открыть» → mark('canvas_open') → прокрутка внутри панели → mark('canvas_scroll')
9. events = await p.evaluate(() => __demo.events())
10. path = await p.video().path(); await p.close(); await ctx.close()
```

Сохрани `Демо/events.json` (`{"video_start_ms": …, "events": …}`) и
`Демо/<имя>_raw.webm`.

- Ответ агента ждать по появлению финального блока, а не фиксированным
  `sleep`: длинное ожидание само сожмётся при монтаже.
- Превью рисуется через canvas: ждать плашку «Отображение может
  отличаться от оригинала». Имя файла нестабильно — искать строку по
  расширению `.xlsx`.
- После двойного клика сразу снимать выделение:
  `getSelection().removeAllRanges()`.
- Кнопки тулбара холста искать по `aria-label` («Действия»,
  «Раскрыть», «Закрыть»).
- Перед зумом сверить итоговые цифры файла с ответом агента. Если в
  файле ошибка, крупно её не показывать и сообщить пользователю.
- Если стенд упал во время записи — перезаписывать целиком: после
  перезагрузки в кадре остаётся красная плашка синхронизации.
- **Синхронизация журнала:** `video_start_ms`, взятый позже `newPage()`,
  сдвигает все метки. После записи сверь момент отправки на листе
  раскадровки с меткой `send`; разницу запиши в `sync_offset` в
  `edit.json`. Ошибочные метки правятся в копии `events_fixed.json`,
  исходный журнал не трогать.
- Журнала нет — разметить события вручную по листам `qa_video.py
  <исходник>` в формате `{"type": …, "t": <секунды>}`.

## 4. Монтаж

`python auto_edit.py Демо/edit.json`. Выход: `<output>.mp4` (основной),
`.webm`, `_poster.png`, `_timeline.json` (для приёмки). Файл `.vtt`
остаётся в `_edit/`: субтитры уже вшиты в кадр, и `.vtt` рядом с роликом
плеер нарисует вторым слоем.

Ориентиры holds: `send` — 3 с; `file_ready` — 3 с (зум 1.8); `result_open`
+ `result_scroll` — 8–15 с (зум 1.3–1.5); `final`/`findings` — 6–8 с.

Без папки `brand/` (публичная копия) карточки рисуются фирменным
градиентом без логотипа и робота.

## 5. Звук

- По умолчанию голоса нет. Тихая музыка (`music`, `music_db` −20 дБ)
  допустима; трек и права на него даёт пользователь.
- Озвучка — только по просьбе. Реплики пишутся в `voiceover.json`, тайминги
  берутся из `_timeline.json`. Текст короткий и разговорный (~2,3 слова в
  секунду), числа — словами, факты — только из ответа агента. Если
  реплика не влезает, текст сокращают, а не ускоряют речь.
- `voiceover_edge.py` — Edge TTS без коммерческой лицензии: в клиентских
  материалах указывать «озвучено синтезатором речи».

## 6. Приёмка

`python qa_video.py Демо/<output>.mp4 Демо/<output>_timeline.json` — код
возврата 0 обязателен. Затем **просмотреть каждый `sheet_NN.png`** и
пройти визуальный чек-лист `qa_report.md`: автоматика не видит чужие
пространства, служебные файлы и перекрытия. Дефект записи исправляется
перезаписью, дефект монтажа — правкой `edit.json`.

## 7. Грабли

- `recordVideo` нужен ffmpeg Playwright: `cmd /c "npx playwright install
  ffmpeg"` (через `cmd /c`, потому что PowerShell запрещает `npx.ps1`).
- Песочница `browser_run_code_unsafe` не хранит переменные между
  вызовами. Контекст записи ищется через `browser.contexts().find(c =>
  c.pages().some(p => p.url().includes('<id>')))`; журнал переживает
  вызовы, потому что лежит в `sessionStorage`.
- Путь к видео узнавать до `page.close()`; файл становится валидным только
  после `close()`.
- `page.click(selector)` телепортирует курсор, поэтому сначала
  `mouse.move(..., {steps: 25})`.
- Рабочую папку `_edit/` и относительные пути в `auto_edit.py` не
  менять: абсолютные Windows-пути ломают filtergraph.

## 8. Чек-лист ролика

- [ ] Сначала титульная карточка, затем сразу демо-пространство; нет
      экранов загрузки и белых кадров.
- [ ] В кадре нет чужих пространств, ФИО, аватаров, служебных файлов,
      сцен отладки.
- [ ] `qa_video.py` даёт PASS; ожидание сжато.
- [ ] Каждый созданный файл показан; итоговые цифры читаются и
      совпадают с ответом агента.
- [ ] Тексты короткие, без опечаток, факты верны; использована одна
      текстовая система.
- [ ] Демо-данные по DEMO-DATA; на финальной карточке — «Данные в демо
      вымышлены».
- [ ] 40–100 с; MP4 H.264 1080p ≤ 20 МБ, WebM, обложка.
- [ ] Листы раскадровки просмотрены.
