# demo-video — съёмка и монтаж демо-ролика

Сними и смонтируй демо-ролик плагина `$ARGUMENTS`. Явный вызов команды —
это просьба пользователя включить слой DEMO-VIDEO.

## Предусловия

- Загрузи навык `skill-craft` и прочитай
  `../skill-craft/Референсы/DEMO-VIDEO.md` целиком. Скрипты монтажа —
  `../skill-craft/Референсы/Съёмка демо-видео/`
  (`analyze_idle.py`, `make_short.py`, `make_subtitles.py`); константы —
  наверху каждого файла. Скрипты копируй в рабочую папку демо, оригиналы
  не правь.
- Плагин развёрнут на стенде (иначе — сначала `deploy-plugin`), есть URL
  пространства на `<cfg:demo_stand_url>` (навык `skill-craft`, раздел
  «Настройки окружения»). Логин выполняет пользователь.
- Инструменты: браузер с Playwright, Python, полный ffmpeg
  (`imageio-ffmpeg`, §5.1). Установку пакетов на машине пользователя
  предложи и выполни только после его согласия.
- Рабочая папка — `backlog/02. Testing/<alias>/Демо/`.

## Шаги

- [ ] 1. Сценарий (§2): демо-данные с заложенными рисками, запрос одной
      фразой, файл прикрепляется в кадре. Согласуй сценарий с пользователем.
- [ ] 2. Запись (§1.1, Playwright recordVideo). Альтернатива §1.2 — только
      если пользователь просит.
- [ ] 3. Анализ статики — `analyze_idle.py` → блоки ≥ 4 с.
- [ ] 4. Момент отрисовки — PNG-пробы (§5.1).
- [ ] 5. Карта правки `segments` в `make_short.py` по правилам §5.2;
      проверь оценку хронометража 80–100 с до рендера.
- [ ] 6. Рендер `_short.webm`.
- [ ] 7. Титры (`make_subtitles.py`, §6): тексты — только о том, что
      реально в кадре. Покажи список титров пользователю до рендера.
- [ ] 8. Приёмка по чек-листу §8 (повторный `analyze_idle.py` на итоге).

## Ограничения

- Озвучку не добавлять — смысл несут субтитры.
- Факты в титрах не выдумывать.
- Публикацию ролика на файлообменник и итоговую страницу делает
  `agent-page` — здесь только видео.

## Формат отчёта

Пути к исходнику, `_short.webm`, `_short_subtitled.webm`, `_short.vtt`;
хронометраж и размер; таблица карты правки; чек-лист §8 с отметками.
